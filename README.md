# Estate App 🏡

A real estate mobile application built with Flutter and Dart as a learning project. The app focuses on providing a simple and user-friendly experience for browsing property listings.

## ✨ Features

- Browse property listings.
- Explore a clean, intuitive mobile interface.

## 🛠️ Built With

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- An Android emulator, iOS simulator, or compatible physical device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Mohamed-Jalab/estate_app.git
```

**2. Navigate to the project directory**

```bash
cd estate_app
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
